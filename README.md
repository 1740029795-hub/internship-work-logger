## 功能概览

### 📊 仪表盘
- 统计卡片：累计日报数、连续打卡天数、本周/本月工时、实习进度条、剩余天数
- 快速写日报：无需跳转页面，直接在工作台填写当天日报
- 最近日报列表：显示最近 5 条记录，点击可编辑
- 本周概览：7 天网格，标记每天是否已记录、显示心情 emoji
- 首次使用引导：未配置实习信息时显示设置提示

### ✏️ 日报管理
- **创建日报**：日期选择、标题、工作内容（必填）、工作时长、心情（5 级 emoji）
- **完成任务**：多行输入，一行一个任务
- **明日计划**：规划下一天的工作
- **困难与收获**：记录遇到的问题和学到的知识/技能
- **标签系统**：输入标签按回车添加，支持多个标签，点击 × 删除
- **自动保存**：每 2 秒自动保存草稿到浏览器 localStorage，刷新不丢失
- **编辑/删除**：按日期定位日报，修改后保存，支持删除（带确认弹窗）
- **列表视图**：按日期范围、标签、关键词筛选，分页浏览
- **Ctrl+S**：快速保存日报

### 📅 日历视图
- **月网格**：标准月历布局，本月日期高亮，今日有蓝色边框
- **状态标记**：绿色圆点 = 工作日已记录，蓝色圆点 = 休息日
- **信息预览**：每个日期格显示标题摘要、心情 emoji、工时
- **月度统计**：顶部显示本月记录天数、工作天数、总工时
- **点击交互**：点击有记录的日期 → 编辑日报；点击空白日期 → 创建日报
- **← → 键**：键盘左右箭头切换月份，无页面刷新（AJAX 加载）
- **月份导航**：上月/下月/今天 按钮，URL 同步更新

### 📝 周报
- **自动生成**：从当周日报智能聚合，提取关键词、完成任务、学习收获
- **结构化模板**：
  - 一、工作概况（工作天数、工时、关键词、工作状态）
  - 二、每日概要（每天标题 + 内容摘要 + 工时）
  - 三、工作亮点（去重后的任务清单）
  - 四、下周计划（取最新日报的计划）
- **手动编辑**：生成后可在文本框中自由修改
- **定稿功能**：点击「定稿」锁定内容，状态变为绿色「已定稿」
- **查看日报**：报告页下方展示当周所有日报列表
- **重新生成**：可重新自动生成覆盖当前内容

### 📄 月报
- **智能聚合**：优先从周报聚合，周报不足则从日报直接生成
- **结构化模板**：
  - 月度总结（工作天数、工时、关键词、各周回顾）
  - 主要成果（各周亮点汇总）
  - 技能收获（从日报 learnings 提取）
  - 反思与不足（从日报 challenges 提取 + 改进建议）
- **级联生成**：生成年报时自动补全缺失的月报

### 📘 年报
- **全面汇总**：整合全年 12 篇月报数据
- **结构化模板**：
  - 年度总结（总工作日、覆盖月份）
  - 总体回顾（按时间线叙述每月概要）
  - 重点项目（所有月报成果汇总）
  - 成长总结（技能成长轨迹）
  - 未来展望（4 条建议方向 + 自定义补充）
- **自动补全**：生成年报前自动补齐缺失的月报

### 📥 导出
- **Word (.docx)**：A4 页面、正规排版、学生信息表、分节标题、页脚
- **PDF**：通过 WeasyPrint 渲染 HTML → A4 PDF（如未安装则提供打印页面回退）
- 中文字体自动适配（微软雅黑 / 黑体）

### ⚙️ 设置
- 学生信息：姓名、学号、学校、专业
- 实习信息：单位、岗位、部门、导师
- 实习时间：开始日、结束日、周起始日（周一/周日）
- **数据备份**：一键下载全部数据为 JSON 文件
- **数据恢复**：上传备份文件恢复（会覆盖现有数据）
- **快捷键表**：展示所有键盘快捷键

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端框架 | **Python Flask 3.1** | 轻量 Web 框架，16 个路由 |
| 模板引擎 | **Jinja2** | 服务端渲染，9 个页面模板 |
| 数据库 | **SQLite3 (WAL 模式)** | 单文件数据库，5 张表，零配置 |
| 前端 | **原生 HTML/CSS/JS** | 无框架依赖，自建设计系统 |
| Word 导出 | **python-docx 1.2** | 纯 Python，无系统依赖 |
| PDF 导出 | **WeasyPrint 62+** | HTML → PDF（可选，未安装时回退） |
| 设计风格 | **自定义设计系统** | 深蓝主色调，专业商务风格 |

## 快速开始

### 环境要求

- Python 3.10 或更高版本
- Windows / macOS / Linux

### 安装与启动

```bash
# 1. 进入项目目录
cd D:\项目\实习工作记录器

# 2. 安装依赖
pip install flask python-docx

# 3. （可选）安装 PDF 导出支持
pip install weasyprint

# 4. 启动应用
python app.py
```

启动后在浏览器打开 **http://127.0.0.1:5000**

### 首次使用流程

1. 打开浏览器访问 `http://127.0.0.1:5000`
2. 点击左侧「⚙️ 设置」，填写实习信息（姓名、单位、起止日期等）
3. 回到工作台，点击「✏️ 写日报」开始记录
4. 积攒一周后，进入「📝 周报」点击「生成周报」
5. 月末生成「📄 月报」，实习结束生成「📘 年报」
6. 点击「📥 Word」导出提交给学校

## 使用指南

### 日报填写建议

| 字段 | 建议内容 | 示例 |
|------|---------|------|
| 标题 | 一句话概括今日重点 | 「完成用户登录模块开发」 |
| 工作内容 | 详细描述做了什么、怎么做 | 「使用 React Hooks 重构了登录页面...」 |
| 完成任务 | 一行一个，具体可量化 | 「完成登录页面 UI 开发」 |
| 明日计划 | 明天要做什么 | 「对接后端登录 API」 |
| 困难 | 遇到的问题 | 「跨域请求配置不生效」 |
| 收获 | 学到的新知识/技能 | 「理解了 CORS 的配置原理」 |
| 标签 | 关键词便于分类检索 | `React, 前端, 登录` |

### 报告生成逻辑

```
日报 ──→ 周报 ──→ 月报 ──→ 年报
  │        │        │        │
  │   聚合7天   聚合4-5周   聚合12月
  │   提取关键词  深度汇总    全面回顾
  │   汇总任务   提取成果    成长轨迹
  └── 原始记录 ──→ 结构化报告 ──→ 导出 Word/PDF
```

### 数据备份

在「设置」页底部：
- **备份**：点击下载，获得包含全部数据的 JSON 文件
- **恢复**：上传之前下载的备份文件，恢复所有数据（注意会覆盖）

## 制作过程

### 需求分析

大学生顶岗实习通常需要向学校提交：
- **日报**：每天的工作内容和时长
- **周报**：每周的工作总结和下周计划
- **月报**：每月的成果汇总和反思
- **年报**：整个实习期的全面回顾

如果全程手动撰写，耗时费力且容易遗漏。需要一个本地工具自动化管理。

### 设计决策

1. **Web 应用而非桌面应用**：浏览器界面灵活，方便在任意设备查看，无需安装额外运行时
2. **SQLite 而非 MySQL/PostgreSQL**：单文件零配置，适合个人本地使用，WAL 模式保证并发安全
3. **服务端渲染而非 SPA**：9 个页面规模不需要前端框架，Jinja2 模板简洁高效
4. **python-docx 而非模板文件**：动态生成 Word，无需维护 .docx 模板
5. **自定义 CSS 而非 UI 框架**：避免引入大型 CSS 库，保持代码可控和加载速度

### 开发阶段

| 阶段 | 内容 | 产物 |
|------|------|------|
| **Phase 1** | 项目骨架 | `app.py`、`database.py`、`base.html`、`style.css` |
| **Phase 2** | 设置页 | `settings.html`、设置读写路由 |
| **Phase 3** | 日报 CRUD | 创建/编辑/删除/列表、标签输入、心情选择器 |
| **Phase 4** | 仪表盘 | 统计卡片、快速日报、最近记录、本周概览 |
| **Phase 5** | 日历视图 | 月网格 + AJAX 加载 + 点击导航 |
| **Phase 6** | 周报 | 自动生成 + 查看编辑 + 定稿 |
| **Phase 7** | 月报+年报 | 级联聚合生成（日报→周报→月报→年报） |
| **Phase 8** | 导出模块 | Word (.docx) + PDF 导出 |
| **Phase 9** | 优化打磨 | Flash 消息、自定义弹窗、加载动画、连续打卡、工时统计、结构化报告、备份恢复、全局快捷键 |

### 技术亮点

- **报告级联聚合**：年报自动补全缺失月报，月报优先使用周报数据，层层汇总不丢信息
- **自定义确认弹窗**：基于 Promise 的异步确认，替代浏览器原生 confirm，样式与整体风格统一
- **日历 AJAX 加载**：切换月份不刷新页面，fetch API 获取数据后动态渲染
- **自动保存草稿**：日报编辑时每 2 秒自动保存到 localStorage，意外关闭浏览器后恢复
- **WAL 模式**：SQLite 的 Write-Ahead Logging 模式，读写并发不阻塞
- **停止词过滤**：内置 200+ 中英文停用词表，关键词提取更精准
- **Tag 芯片输入**：类 Notion 的标签输入体验，回车添加、Backspace 删除、点击 × 移除
